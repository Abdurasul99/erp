# WOW Combinator — сайт оператора платформы Wave

Отдельный сайт: собственная сборка, никакой связи с `mywarehouse.uz` и его
фронтом. Переход в продукт — только ссылками наружу.

## Локально

```bash
cd wow-site
npm install
npm run dev      # http://localhost:5173
npm run build    # dist/
```

## Деплой на Vercel

1. New Project → импортировать репозиторий.
2. **Root Directory: `wow-site`** (иначе Vercel соберёт основной фронт).
3. Framework Preset: **Vite** (подтянется из `vercel.json`).
4. Build Command `npm run build`, Output Directory `dist` — уже прописаны.
5. Deploy. Получите адрес вида `wow-combinator.vercel.app`.

Когда появится свой домен — добавьте его в Project → Settings → Domains.
Продукт остаётся на `mywarehouse.uz`, сайт на него только ссылается.

## Что где править

| Файл | Что в нём |
|---|---|
| `src/data.js` | тарифы, цены, матрица возможностей, сравнение с рынком, FAQ, контакты |
| `src/App.jsx` | разметка страницы |
| `src/styles.css` | оформление (светлая тема, без эмодзи — канон проекта) |
| `ЭКОНОМИКА-ВНУТРЕННЯЯ.md` | себестоимость и обоснование цен — **не публикуется**, в `dist` не попадает |

**Важно.** Матрица в `src/data.js` описывает реальные разделы системы
(`frontend/src/owner/modules.js`, 80 инструментов). Добавили инструмент в
продукт — обновите и здесь, иначе сайт начнёт обещать не то, что открывается.

Контакты (`CONTACT_TG`, `CONTACT_PHONE` в `src/data.js`) сейчас заглушки —
подставьте настоящие до публикации.
