# WareApp — Real-time нагрузочный симулятор

Отдельный веб-симулятор, который через **MQTT (встроенный брокер Aedes)** в реальном времени
прогоняет полный бизнес-цикл WareApp (приход → продажа → касса) на нескольких компаниях
одновременно, **через реальный API** (`/api/stock/income`, `/api/stock/outcome`, `/api/cash/*`),
и измеряет, сколько операций/секунду выдерживает сервер и БД.

## Стек
- **Node** — оркестратор + брокер (Aedes) + консьюмеры + control-API.
- **Vue 3** (CDN, без сборки) — панель управления (`web/index.html`).
- Запись данных — только через реальный WareApp API. Все сущности помечаются `[SIM]`.

## Архитектура
```
agents.js  --MQTT(sim/<co>/<br>/<type>)-->  Aedes(127.0.0.1)  -->  consumer.js  --HTTP--> WareApp API --> Postgres
   (публикуют реалистичные операции с заданным темпом)        (пул конкурентности, метрики)
index.js — control-API (:4000) + раздача панели + публикация stats
bootstrap.js — провижининг компании через API (admin→company→branches→users→products→начальный приход)
cleanup.js — удаление всех [SIM]-данных
```

## Запуск (на сервере, рядом с WareApp)
```bash
cd /var/www/wareapp/simulator/server
npm install
SIM_TOKEN=<секрет> pm2 start index.js --name wareapp-sim
```
Панель: `http://<сервер>:4000/?key=<SIM_TOKEN>`

Конфиг через env (`config.js`): `SIM_API_BASE` (по умолч. `http://127.0.0.1:3001/api`),
`SIM_CONCURRENCY` (одновременных запросов, по умолч. 60), `SIM_INIT_STOCK`, `SIM_TOKEN` (ключ доступа).
Креды БД и `JWT_SECRET` автоматически берутся из `../../backend/.env`.

## Панель
1. Задать конфиг (компаний / филиалов / складовщиков / продавцов / кассиров / товаров / клиентов) → **Создать компании**.
2. Выставить **темп (msg/с)** → **Старт всех**. Живые KPI: опубликовано/с, успешно/с, ошибок/с, in-flight, очередь, latency p50/p95/p99 + график.
3. У каждой компании — **логин/пароль учредителя** (войти в WareApp и убедиться, что данные наполняются) + **«Проверить инструменты»** (читает все окна под founder → зелёный/красный).
4. **Стоп всех** → **Очистить [SIM]**.

## Очистка вручную
```bash
node cleanup.js   # удалит все [SIM]-компании и их данные
```

## Безопасность
- Брокер слушает только `127.0.0.1` (внешний publish невозможен).
- Control-API защищён ключом `SIM_TOKEN` (без ключа → 401).
- Порт 4000 открыт на сервере; держать симулятор запущенным только на время теста (`pm2 stop wareapp-sim`).
